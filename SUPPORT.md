## Questions and bug reports: GitHub issues

[Open an issue](https://github.com/clearobject/halow-alert-releases/issues/new/choose) in this repository and pick a form:

- **Bug report**: something does not work as documented. The form asks for your setup, operating system, how the HaLowLink is connected, the version, and the `doctor` output.
- **Question**: how to do something, or whether halow-alert fits your use.

Issues are public. **Never paste tokens, passwords, HaLow network passphrases, your `.env` file or the output of `docker compose config`.** If a log line contains something you would rather not publish, replace it with `<removed>`.

## The hardware

For the wearable or the HaLowLink itself (powering on, charging, silencing an alarm, the admin password, the HaLow network details, joining another wearable, returning a unit), ask **your ClearObject contact**. Do not post hardware passwords in issues.

## Security

Report vulnerabilities privately, as described in [SECURITY.md](SECURITY.md). Do not open a public issue for them.
